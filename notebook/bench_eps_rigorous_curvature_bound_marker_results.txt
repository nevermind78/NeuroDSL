RMSNorm(x)_j = gamma_j * x_j / r(x),  r(x)=sqrt(mean(x^2)+eps).
Jacobien : d y_j/d x_k = gamma_j*[delta_jk/r - x_j x_k/(nc*r^3)].
Preuve : ||x||^2/nc <= r(x)^2 (car eps>=0) => la matrice (1/r)(I - xx^T/(nc r^2)) a une norme
d'opérateur <= (1/r)*(1 + ||x||^2/(nc r^2)) <= 2/r. Donc EXACTEMENT (pas une borne relâchée -- une
inégalité triangulaire propre) :  ||J_RMSNorm(x)||_op <= 2*max_j|gamma_j| / r(x).
Ordres 2 et 3 : PAS de forme fermée aussi simple à main levée sans risque d'erreur d'algèbre --
utilisation de l'homogénéité de degré 0 EXACTE de RMSNorm (au terme eps~1e-6 près, négligeable ici
car mean(x^2) est d'ordre 1 dans ce réseau -- eps 6 ordres de grandeur plus petit) : D^k y(x)[v,..,v]
= r(x)^{-k} * D^k y(u)[v,..,v] où u=x/r(x) est de rayon unité (rms(u)=1). La 'constante angulaire'
D^k y(u) est cherchée NUMÉRIQUEMENT (dense, sur la fonction FERMÉE connue, pas sur le réseau) sur
la sphère unité -- voir ci-dessous, avec le nombre d'échantillons déclaré (certification numérique,
pas une preuve exhaustive du sup global, mais fonction lisse sur domaine compact).
